Termania

The GPU-accelerated multi-pane terminal

A grid-based terminal emulator with LLM integration, 10 plugin types, and a Unix socket API for external control. Built with wgpu and Rust.

Install with Cargo
cargo install termania ⎘
Get Started View on GitHub

Built for Power Users

▦

Multi-Pane Grid

Tile terminals in a configurable grid layout. Resize dynamically, swap panes with keyboard shortcuts, and broadcast input to all panes simultaneously.

⚡

GPU Rendering

Every glyph is rendered on the GPU via wgpu. Buttery-smooth scrolling, zero tearing, and efficient redraw even with dozens of active panes.

✨

LLM Integration

Open the command overlay and describe what you want in natural language. Supports Anthropic, OpenAI, Ollama, and any OpenAI-compatible endpoint.

🔌

Text Tap API

A Unix domain socket server that lets external processes subscribe to pane output, send input, and execute structured actions. Scriptable via JSON.

🧩

10 Plugin Types

Terminal, WebView, Notes, Screen Capture, File Browser, Process Monitor, Log Viewer, Markdown Preview, System Info, and Git Status — all in one window.

⚙

TOML Config

Two-file configuration: config.toml for appearance and termania.toml for session layout. Per-project sessions load automatically.

Quick Start

1

Install

cargo install termania
2

Create a session file

# termania.toml
title = "My Project"
rows = 2
cols = 2

[[panes]]
title = "Editor"
cwd = "~/projects/myapp"
watermark = "EDIT"

[[panes]]
title = "Server"
cwd = "~/projects/myapp"
initial_commands = ["npm run dev"]

[[panes]]
title = "Tests"
cwd = "~/projects/myapp"
initial_commands = ["cargo watch -x test"]

[[panes]]
type = "webview"
title = "Docs"
url = "http://localhost:3000"
3

Launch

# From your project directory (auto-loads ./termania.toml)
termania

# Or specify a session file explicitly
termania path/to/session.toml
